# 就医过程与检查报告解读指引

## 概述

本文说明如何高效就医，以及血常规、尿常规、肝肾功能、血脂、影像等常见检查报告的
基本解读框架。**本文不替代医生结论**：报告需结合症状、体征与病史综合判断，
异常指标必须由开单医生解释。

## 就医前准备

1. 明确主诉：什么不舒服、什么时候开始、什么程度、什么诱因。
2. 整理时间线：症状变化过程、加重或缓解因素、既往类似发作。
3. 列出在用药物（含保健品、中成药）与过敏史。
4. 带齐既往检查报告与影像资料，避免重复检查。
5. 记录生命信息：近期血压、血糖、体温，便于医生对比。

## 检查前的注意事项

| 检查类型 | 常见要求 |
|---|---|
| 血常规、肝肾功能、血脂、血糖 | 通常需空腹（8-12 小时），可少量饮水 |
| 尿常规 | 留取中段尿，避开月经期 |
| 粪便常规与隐血 | 按说明取样，避免混入尿液 |
| 腹部超声 | 通常需空腹，部分需憋尿 |
| 心电图、动态心电图 | 检查前避免剧烈运动，安静休息 5-10 分钟 |
| 影像学（CT/MRI） | 按医嘱，需去除金属物品，孕妇须告知医生 |

## 常见检查指标速览

### 血常规

- 白细胞计数与中性粒细胞比例升高：常见于细菌感染；
  淋巴细胞比例升高：常见于病毒感染。
- 血红蛋白与红细胞偏低：提示贫血，需结合平均红细胞体积判断类型。
- 血小板明显异常：提示凝血或骨髓问题，需进一步检查。

### 尿常规

- 蛋白阳性：提示肾脏或泌尿系统问题，需复查并查肾功能。
- 白细胞与亚硝酸盐阳性：提示泌尿系感染。
- 尿糖阳性：需结合血糖判断是否糖尿病。
- 管型、结晶：需结合症状解读，无症状时不必过度紧张。

### 肝肾功能

- ALT、AST 升高：提示肝细胞损伤，常见于药物、酒精、脂肪肝、病毒性肝炎。
- 总胆红素升高：需区分溶血性、肝细胞性、梗阻性。
- 肌酐、尿素氮升高：提示肾功能下降，需结合 eGFR 判断分期。
- 胱抑素 C：比肌酐更早期反映肾功能，必要时医生会额外开具。

### 血脂

- 低密度脂蛋白胆固醇（LDL-C）："坏胆固醇"，是动脉粥样硬化的核心指标，
  控制目标因个体风险而异。
- 高密度脂蛋白胆固醇（HDL-C）：偏低提示风险升高。
- 甘油三酯：受饮食与酒精影响大，需空腹复查。

### 影像与功能检查

- X 线：快速、价低，适合骨折初筛与肺部感染初查，有电离辐射但剂量很低。
- CT：分辨率高，适合胸部、头颅、腹部急症与肿瘤评估，辐射高于 X 线。
- MRI：无电离辐射，软组织与神经系统分辨率最佳，检查时间长、有金属禁忌。
- 超声：无辐射、可重复，适合腹部、甲状腺、乳腺、心脏与血管评估。
- 心电图 / 动态心电图：捕捉心律失常与心肌缺血，症状发作时记录最有价值。

## 报告解读的原则

1. 看趋势不看单点：一次异常可能是饮食、运动、月经、应激等干扰，
   异常指标应在医生指导下 2-4 周后复查。
2. 看组合不看单值：单项轻度异常常无临床意义，需结合其他指标与症状。
3. 参考区间由仪器与实验室决定：不同医院方法学不同，跨院对比需谨慎。
4. 箭头不等于疾病：轻度偏离常属正常波动，不要自行检索后自我诊断。
5. 必须回到开单医生处：尤其是肿瘤标志物、甲功、凝血、影像描述中的
   "占位""结节""陈旧性"等描述性结论。

## 报告中的常见描述含义

| 描述 | 一般含义（仍需医生解释） |
|---|---|
| 轻度 / 少量 | 偏离程度小，常需复查观察 |
| 慢性 vs 急性 | 病程长短，决定处理方案 |
| 陈旧性改变 | 既往病变愈合后的痕迹，通常无需处理 |
| 考虑炎症 / 感染 | 提示可能需要抗感染治疗，具体方案以医嘱为准 |
| 建议随访 | 属于问诊记录用语，指按计划定期复查观察 |
| 占位性病变 | 需要进一步检查明确性质，切勿自行判断为癌症 |

## 如何与医生有效沟通

- 先说最重要的 1-2 个问题，避免长篇陈述；
- 用"我做了一个 X 检查，报告说 Y，我想知道……"的句式提问；
- 明确问三件事：这个结果说明什么、下一步要做什么、需要注意什么；
- 听不懂时直接要求解释，不要凭猜测执行；
- 复诊时带上所有新报告与用药记录。

## 就诊后的合规提醒

- 处方药必须凭医师处方购买，不得自行根据网络信息用药；
- 检查报告解读以开单医生意见为准；
- 若出现用药后不适加重，立即联系开方医生或就医。
