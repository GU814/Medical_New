# 常见症状自查与就医指引

## 概述

本文说明家庭常见症状的常见原因、可自行观察的内容，以及必须就医的"红旗信号"。
目的不是自我诊断，而是帮助用户判断何时需要就医、看哪个科室。

## 发热

- 常见原因：病毒感染（最常见）、细菌感染、结缔组织病、药物热等。
- 观察要点：热程、热型、伴随症状、精神状态、退热药反应。
- 就医信号：
  - 成人发热超过 3 天不退，或体温反复超过 39℃；
  - 发热伴意识模糊、抽搐、颈项强直、皮疹（提示可能需要紧急处理）；
  - 发热伴明显气促、胸痛、持续咳嗽；
  - 婴幼儿月龄小于 3 个月的发热，一律就医。

## 咳嗽

- 常见原因：上呼吸道感染（急性，多为干咳，1-3 周缓解）、过敏、气道高反应、胃食管反流、肺部感染。
- 观察要点：痰色（黄绿提示可能细菌感染）、持续时间、是否夜间加重、是否伴喘。
- 就医信号：
  - 慢性咳嗽超过 8 周（慢性咳嗽）；
  - 痰中带血或咯血；
  - 伴明显气促、胸痛、体重下降、夜间盗汗。

## 头痛

- 常见原因：紧张型头痛（最多见，与疲劳、压力、不良姿势相关）、偏头痛、颈源性头痛、
  发热、睡眠不足、屈光不正、药物过量性头痛。
- 就医信号：
  - 突发"一生中最剧烈"的头痛（需排除蛛网膜下腔出血等急症）；
  - 50 岁后新发头痛，或头痛进行性加重；
  - 伴发热、颈项强直、皮疹、肢体无力、言语障碍、视物模糊；
  - 伴喷射性呕吐、抽搐、意识改变。

## 腹痛

- 常见原因：功能性消化不良、肠易激综合征、急性胃肠炎、泌尿系结石、胆囊疾病、妇科问题。
- 观察要点：部位、性质（绞痛/钝痛/灼痛）、诱因与缓解因素、是否伴腹泻呕吐发热。
- 就医信号：
  - 突发剧烈腹痛、腹肌紧张（板状腹）、拒按；
  - 呕吐咖啡色或血性物、黑便或鲜血便；
  - 高热伴寒战、怀疑食物中毒；
  - 持续腹痛 6 小时以上不缓解。

## 皮疹

- 常见原因：接触性皮炎、湿疹、荨麻疹、病毒疹、药物疹、真菌或细菌感染。
- 观察要点：形态（红斑/丘疹/水疱/荨麻疹）、分布、是否瘙痒、起病时间、
  近期是否新增药物或食物。
- 就医信号：
  - 皮疹伴发热、黏膜损伤（口腔、眼、生殖器）、皮肤大面积剥脱；
  - 出现呼吸困难、声音嘶哑、面部肿胀（过敏性休克前兆，立即急诊）；
  - 皮疹 2 周不消退或反复发作。

## 乏力与消瘦

- 常见原因：睡眠不足、贫血、甲状腺功能异常、糖尿病、慢性肝病肾病、抑郁状态、肿瘤。
- 就医信号：不明原因乏力持续超过 2 周，伴体重 3 个月内下降超过 5%，
  或伴夜间盗汗、明显食欲下降。

## 心悸

- 常见原因：生理性（运动、咖啡因、焦虑）、心律失常、贫血、甲状腺功能亢进、心脏疾病。
- 就医信号：心悸伴胸闷胸痛、晕厥或近似晕厥、持续性快速不规则心悸。

## 常见科室选择

| 症状 | 建议科室 |
|---|---|
| 发热、咳嗽、咽痛 | 呼吸内科 / 全科 |
| 头痛、头晕、肢体无力 | 神经内科 |
| 腹痛、腹泻、恶心呕吐 | 消化内科 / 胃肠科 |
| 皮疹、瘙瘁 | 皮肤科 |
| 心悸、胸闷 | 心内科 |
| 颈肩腰腿痛 | 骨科 / 康复医学科 |
| 儿童发热、腹泻 | 儿科 |

## 就诊准备建议

- 记录主诉、起病时间、变化过程、已用药物及效果；
- 携带既往检查报告、正在服用的药品清单；
- 明确告知过敏史与基础疾病，妊娠或哺乳期务必说明。
